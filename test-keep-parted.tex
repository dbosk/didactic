% A lead-in and what it leads into, a list, a listing or code side by side, on
% one page or parted (didactic): correct or warn.  Each case has a kind:
%   tie   parted only with a warning that names its line, and together without one;
%   free  it follows the end of a list, which is a place to break that LaTeX means,
%         or a break that you asked for, so it is parted here, and nothing warns.
% The words LEAD<case> and FIRST<case> are the last line of the lead-in and the
% first line of what it leads into.
%
% S1  A list inside a box in the lead-in (a note, a footnote, a minipage, a float)
%     doesn't make the list after it follow the end of a list.
%     n1 \ltnote, n2 \footnote, n3 \marginpar, n4 a minipage holding a center,
%     n5 a figure holding a center and no caption, after the lead-in (and in it: S4).
% S2  \pagebreak[1] in the first line of a lead-in of three lines: p1, at rooms 4 to 7,
%     before a listing in a center, a quote or an item, code side by side in a center,
%     an itemize and an enumerate; p2 in the first line of one of two lines, room 4.
% S3  After the end of a list, a listing in a center (f1a), a quote (f1b) or an item
%     (f1c), and code side by side in a center (f1d); after a center (f1e), a quote
%     (f1f), a listing (f1g) and code side by side (f1h), a listing in a center; after
%     code side by side (f1i) and a center (f1j), a listing.  Room 3.
% S4  A float or a note that ends the lead-in's paragraph, then a list (n5a, t1a to
%     t2c), at rooms 1.25 to 5; p3a and p3b: \pagebreak[1] that ends the lead-in is a
%     break asked for, and so is one in vertical mode before a center (p3c); a bare
%     \penalty before a listing on its own is silent (p3d), as the docs say.
% S5  Code side by side whose page ended before it, so a note on the next page sets
%     \outputpenalty: after \vspace (q1), a display (q2) or in a center (q3, p1m).
% R   A rule right after the lead-in, then a list, rooms 1.25 to 2, without a blank line
%     after the rule (r1a to r1f) and with one (r2a to r2f): no place to break between
%     them, so the list and the lead-in move together, silently.  But after space and a
%     thicker rule (r3a to r3c) there is a place to break.
% Round 6.  L1, L2: \ltnote or \marginpar ends the lead-in: no place to break, together.
%     G1, G2: glue, then a rule, no blank line: a place to break before the rule; G3 the
%     same after a blank line, and g3e after \nobreak, where the glue is no place to break.
%     F3: a float in the middle of a one-line lead-in; F4, F5: a float at its end, then
%     \label or \footnote.  B1: after a list, \centerline and its kin lead into a
%     listing in a center (b1a to b1e), a listing (b1f) or a list (b1g): that is a
%     lead-in.  M1: \pagebreak[1] in the last (only) line
%     of the lead-in, not at its end, is a break within it, before a center listing and
%     an itemize alike; and \pagebreak[0] there (m1g to m1i).  P4: \pagebreak[1] and then a
%     float end the lead-in: the float makes it no break asked for.  M2: the same in the
%     last line of a long lead-in, before a center listing and an itemize, rooms 4 to 7.
%

% pages of the words.
