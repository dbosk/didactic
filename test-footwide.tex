% Test of noteoverflow=foot (didactic): a footnote that goes to the foot is set
% there as a footnote at the foot is, in the width of the text, and its text runs
% once; and which footnotes are plain (set once, into a line per paragraph, and
% broken for the margin and the foot) and which aren't.  The margin is filled by
% a tall note, so that the footnotes go to the foot.  Each note starts with a
% word of its own (NOTEx); most end with ONCE and a counter it steps, which reads
% 1 if the text ran once (or, for the notes that aren't plain, if its counter
% was set back), and RUNS with a count of TeX's stepped globally, which no one
% sets back: 1 if the text ran once, 2 for the notes that aren't plain, whose
% version at the foot is the second of three runs.  Cases, by \def\testcase{...}:
%   plain     a sentence, whole at the foot;
%   cite      a citation (biblatex, verbose, autocite=footnote) with NOTEA as its
%             prenote and a long postnote, whole at the foot (it has no ONCE);
%   url       a citation of a work with a URL, with hyperref's coloured links;
%   prepost   a citation with a pre- and a postnote;
%   reuse     the same work cited twice on the page: the second reuses the note;
%   twopar    two paragraphs;
%   mixed     \emph, inline math, \\ and \linebreak;
%   color     \textcolor;
%   linewidth a box of .01\linewidth, which is measured where \linewidth is half
%             as wide as TeX allows: LWA and LWB far apart (a limit, pinned);
%   list      an itemize: not plain, the fallback;
%   display   a displayed equation: not plain;
%   parbox    a \parbox{\linewidth}: not plain;
%   vspace    \vspace between two paragraphs: not plain;
%   huge      a paragraph too long for one line: not plain;
%   split     a long sentence near the foot, \testN lines down, split over two
%             pages;
%   wait      the same and a second footnote in the same line, which waits;
%   bs        a footnote with \\ that stays in the margin (no tall note): the
%             line after \\ starts at the margin's edge, as in a margin note
%             without didactic (review P4);
%   fnmark    a footnote with a \footnotemark in it, in the margin: its own
%             mark, 1, before NOTEA (review P5);
%   lang      a footnote of long German compounds called out in
%             \foreignlanguage{ngerman} in English text, at the foot: broken as
%             the same footnote set at the foot by LaTeX (\testlangref) is
%             (review P3);
% \testhyper loads hyperref.  test-footwide.py checks the outcome from the PDF and
% the log.
