% Test that a listing that starts a column apart from its lead-in warns (didactic):
% no page is shipped out between the columns, and only \outputpenalty knows the break.
%
% Build: see the Makefile; test-check.py checks the warnings.
%   M  A lead-in at the foot of the first column, a note, and a listing: the listing
%      starts the second column, and warns.
%   C  Control: a lead-in and a listing with nothing between: they go along.
%   O  A first column overfull with what can't part: no page is shipped out at the end of
%      the column, so the warning names the page of the listing, not the last page
%      shipped.  Two columns of rules come first, so that the lead-in starts the column
%      by a break of the page's own: right after \clearpage, it would first end a column
%      with nothing in it, and ship out the page at the second.
%   R  The same with code side by side.
%   T  A second column overfull: then a page is shipped out, the one it names.
