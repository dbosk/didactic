% A released tie warns once, and names the source's file and line (didactic).
%
% In each case below moving the heading and the lead-in would leave more than
% keepmaxgap lines empty, so the tie is released and what follows the lead-in starts
% the next page.  That has its warning, and the check of where a listing ended up, which
% would also see it starting a page apart from its lead-in, stays quiet.
%   V  A listing.
%   P  Code side by side.
%   N  A chunk that noweb sets itself.
%   W  A chunk woven for minted.
%   M  A listing whose lines come from minted's file: the warning names this file's
%      line, not that file's.
%   G  A listing from a file that PythonTeX wrote: the same.
%   I  A list whose first line seems to fit, by a line of the text, and doesn't: under
%      a heading the club penalty is still 10000 there, and the list still can't stay.
% The space before a list stays what it is, when the tie is released and what is
% written to the .aux comes between that space and the list.
%   A  Without keepleadin: nothing is written there.
%   B  Past the limit, and the first item fits.
%
% Build: see the Makefile; test-check.py compares the warnings with the words' pages.
