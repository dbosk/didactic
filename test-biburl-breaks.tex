% Test of where URLs break in citations and the bibliography (didactic,
% biburlpenalty, #89).  Each case is a page: "CASE <name> <width>" and a
% narrow box with a full citation, or a narrow bibliography;
% test-biburl-breaks.py reads the words of the PDF with their places,
% makes lines of those on one baseline, and checks where the lines break
% inside each URL.
%
% Build: see the Makefile, which runs it in four modes, each time with
%   \def\testmode{default|on|same|lua}
% (default: no options; the others biburlpenalty=9000; same: pdflatex, OT1
% and \urlstyle{same}; lua: lualatex) and then the script, with the mode.
%
% The URLs, by what their pieces (what lies between two places where
% url.sty breaks) do in the box:
%   fits, w1, w3, w4: all pieces fit.  Never a break after a letter or a
%     digit.  w1 and w3 have %-escapes, which url.sty breaks after; w4 has
%     _, which it breaks after too, also when it sets it itself (OT1 and
%     \urlstyle{same}).
%   long: a piece of 70 letters, wider than the box.  With biburlpenalty
%     it breaks after letters in that piece, the last resort; by default
%     it doesn't, and runs into the margin, as with biblatex alone.
%   m40: a piece of 40 letters.  In the 3 cm box and in a margin note it
%     is wider than the line (though not than \textwidth), so it breaks
%     after letters; in 8 and 9 cm boxes it fits on a line of its own, and
%     the line before it ends short rather than run over.  (The margin
%     note isn't set by default: the piece runs off the paper there.)
%   esc: in a box of width 0, where TeX breaks wherever it may, so the
%     lines show every place to break: letter breaks, but never inside
%     https:// or between the two digits of a %-escape.
%   arch: in a box of width 0 too: an archived URL, with a second
%     https:// inside, where url.sty doesn't break between the slashes, as
%     TeX doesn't after a / right after a :, nor after a % right after a /;
%     with biburlpenalty that stays so.
%   rel1, rel2: in boxes of width 0 too, URLs with :: and -- (two
%     relations, between which TeX puts no penalty) and with /: (a binary
%     character before a relation, which TeX takes for an ordinary one).
%     The script compares their breaks with those of the default mode,
%     which are url.sty's own: with biburlpenalty there may be no others
%     than those and letter breaks, and none of those may be missing but in
%     the scheme.
%   para: fits in the middle of a paragraph, at widths where TeX sets every
%     line full in its first pass: no line but the last ends short.
%   outer: fits, with a \UrlLeft and \UrlRight of the document's own, [
%     and ], which must still be there.
% With biburlpenalty: never a break inside https://, and no Overfull
% \hbox.  The URLs have no -: a word that ends in one at the end of a line
% is joined to the next one by pdftotext.  In OT1's roman fonts _ is a
% rule, not a character, so the script finds it in the URL by the
% characters around it.
