# Deliberate breaks of didactic.dtx, and which tests catch them.  Run them with
#   make mutants                  all of them
#   make mutants MUTANTS="M1pen"  those named
# which is test-mutants.py; each runs in a copy of the tracked files.  The format is
# that of mutate.py --batch from the testing skill: blocks separated by blank lines, a
# line `LABEL FILE`, then the old text as `- ` lines and the new as `+ ` lines, each old
# text occurring exactly once.  Lines with # are comments, and two kinds mean something:
#   #: GROUP              which tests run (below)
#   #= killed|survived    what it did at the last full run, with what killed it
# test-mutants.py fails if a mutant does something else than that says.
#
# Last full run: at 3c059c3, with 3 jobs, on a loaded 8-core machine, about two hours
# (six if one at a time), and it took about 100 MB of disk at a time; o_lastmoved at
# b9c6721, with the row added for it.  After a change to the code or to the tests that
# a mutant looks at, its outcome below is from before that.
#
# Groups, in test-mutants.py, with the time for one mutant on a loaded machine:
#   include  test-marginfloat-include, and test-check.py on it and -all (half a minute)
#   title    test-frametitle-floats, and test-check.py on it
#   format   test-format (seconds)
#   keep     test-keep, -tall, -tall100, -chain, -huge, -blank, -leadin, -leadin-off,
#            -overfull, -multicol, -twocol, -once, and test-check.py on those with a check
#            (three to five minutes)
#   noweb    test-keep-noweb, -noweb-break, and test-check.py on them (a minute)
#   rules    the small test-keep documents, test-keep, -heading, -nogap, -once, and the
#            sweep in variants m and s, against plain LaTeX's version (three to eight)
# All with pdflatex, for speed; make all uses xelatex.
#
# A kill needs a named reason: the targets are named, and a full disk is an ERROR.  A
# mutant that breaks a build also fails, so these keep the document compiling.
#
# Not run against these mutants: the sweep's variants a, s3 and e, test-keep-stale,
# test-keep-chapter, and the rest of make all.
#
# Code that no test kills is marked survived below, and named here:
#   \if@fcolmade, in the hook on shipout/before, mutant M10fcol: it stops a float page
#   right after the full page being named as the full page.  Every attempt at a test
#   shipped the float page before the full page.
# The check names a page it can't be sure of there, so a wrong page in a warning is what
# could pass unseen, not a wrong layout.
