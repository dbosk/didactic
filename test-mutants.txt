# Deliberate breaks of didactic.dtx, and which tests catch them.  Run them with
#   make mutants                  all of them
#   make mutants MUTANTS="M1pen"  those named
# which is test-mutants.py; each runs in a copy of the tracked files.  The format is
# that of a batch file of mutate.py: blocks separated by blank lines, a
# line `LABEL FILE`, then the old text as `- ` lines and the new as `+ ` lines, each old
# text occurring exactly once.  Lines with # are comments, and two kinds mean something:
#   #: GROUP              which tests run (below)
#   #= killed|survived    what it did at the last full run, with what killed it
# test-mutants.py fails if a mutant does something else than that says.
#
# Last full run: at e4e71ad, with test-mutants.py --jobs 5, 3 hours 20 minutes on an 8-core
# machine with other jobs (make mutants uses the script's default of two jobs, so about
# twice that); the outcomes below are from it.  The code is the same since, but
# for test-noteoverflow-lua and the Makefile's default engine, which no mutant group runs.
# After it, rows were added to test-keep-parted for R6vspaced, o_ifpend and o_ifglue, which
# that run left surviving as round 8's check of the page caught their old rows, and a
# sample (x_two and three mutants of each group, these among them) was run again.  After a
# change to the code or to the tests that a mutant looks at, its outcome below is from
# before that.  The rounds of review of the branch are on GitHub, dbosk/didactic#67 and the
# pull requests it names.
#
# Groups, as GROUPS and KEEP in test-mutants.py, with the time for one mutant in that run
# (five at a time) and the time of the group's first run on the code as it is:
#   format   test-format (3 s; 2 s)
#   include  test-marginfloat-samepar, -include, and test-check.py on those and on
#            -include-all (25 s; 13 s)
#   title    test-frametitle-floats, -boxes, and test-check.py on them (27 s; 20 s)
#   keep     test-keep, -tall, -tall100, -chain, -huge, -blank, -leadin, -leadin-off,
#            -overfull, -multicol, -twocol, -once, -first, -noweb, -noweb-break, and
#            test-check.py on those with a check (2.5 to 4 minutes; 1.5)
#   noweb    test-keep-noweb, -noweb-break, and test-check.py on them (16 s; 8 s)
#   parted   test-keep-parted, and test-check.py on it (11 s; 6 s)
#   rules    test-keep-heading, -nogap, -style, -columns, -guard, -pagereset, -nofiles,
#            -nofiles0, -box, -addvspace, -club, -club-article, -breakcode-late, -filbreak,
#            -flush, test-keep, -once, -enumitem, -include, test-check.py on -once and
#            -enumitem, and the sweep in variants m, s, k, m3, c, k3 and a, against their
#            references (5 to 9 minutes; 7)
#   biburl   test-biburl, which builds test-biburl-overfull and test-biburl-breaks (in
#            five modes, under pdflatex and lualatex) (1 to 2 minutes; 1.5);
#            with the Makefile's engines, as the target chooses them
#   footcite test-noteoverflow-foot, its job default only (CASES=default), against the
#            marginfix found or $MARGINFIX (about 1 minute)
